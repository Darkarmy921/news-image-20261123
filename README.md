One image that sums up the world's news of **Monday 23 November 2026**:
44 verified stories from 7 regions — COP31 ending with no deal, Democrats
clinching 258 House seats, NATO meeting over Russian missiles in Poland,
Nepal's PM in New Delhi, and the weekend's sport — drawn as a newspaper
front page. Every story traces to a real report dated 22–23 November 2026;
see NEWS.md for the story list and its sources.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is standard library only: it draws the page from glyph bitmaps
baked into `fontdata.py` and writes a deterministic 1024×1024 PNG to
`entry.png`. No network, no clock, no random — the same run always writes
the same bytes.
